## 🚀 Key Projects

### 1. AlgoCanvas  
알고리즘 흐름을 직관적으로 이해할 수 있도록 시각화한 프로젝트  

👉 https://github.com/qdcv0272/AlgoCanvas  

- Zustand 기반 상태 관리로 고빈도 상태 변화 효율적 제어  
- 불변 스냅샷(buildSteps) 구조로 알고리즘 실행 흐름 관리  
- TypeScript 적용으로 런타임 오류 감소 및 안정성 확보  

---

### 2. Used-Shopping  
실시간 데이터 흐름과 사용자 신뢰를 고려한 중고거래 서비스  

👉 https://github.com/qdcv0272/Used-Shopping  

- Firebase 기반 인증, 데이터 저장, 실시간 채팅 구조 구현  
- onSnapshot을 활용한 실시간 데이터 동기화  
- 클라이언트 필터링 및 캐싱 전략으로 불필요한 서버 호출 감소  
- 예외 처리 기반 안정적인 서비스 흐름 설계
